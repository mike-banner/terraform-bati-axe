## Problèmes de départ
1. **Dette technique** :
   - `tests/badges.test.ts` cassé : `BadgeEntrepriseVerifiee` utilise `bg-green-100` alors que le test (et le badge jumeau `BadgeDecennaleCertifiee`) attend `bg-[#F8FAFC]` (palette Sketch 001) — dérive de palette non rattrapée.
   - Suite e2e Playwright **jamais lancée** : le bundle Chromium de Playwright ne s'initialise pas dans le sandbox (dette connue dans STATE.md) ; en plus les specs simulateur dataient de l'ancien flux (catégorie → description → budget → délai) alors que le simulateur est passé à 6 étapes (type de rénovation → pièces → surface → gamme → localisation → fork aides → coordonnées).
   - Branche locale `test-fix` : 3 commits de docs obsolètes (STATE/ROADMAP anciens), superseded par le resync 2026-08-23 (PR #48).
2. **P9 — Mobile QA + états vides** : « 80% de la première impression d'un nouveau user ». Jamais audité en viewport mobile ; états vides jamais vérifiés de bout en bout.
3. **P5 — Feedback loop « refus → marché »** : logique `shouldRelaunch`/`canRelaunch` unit-testée (lead-feedback.test.ts) et câblée dans `decision.post.ts`, mais le flow d'orchestration complet (décision → tous refusés → leads 'lost' + relaunch_count + email) n'a jamais été testé de bout en bout.

## Décisions
- **Playwright** : basculer sur le Chrome système (`channel: 'chrome'`) au lieu du bundle Chromium — résout l'init cassée dans le sandbox. C'est une config locale, pas un changement de dépendance.
- **Test badge** : aligner le composant sur `bg-[#F8FAFC]` (cohérent avec le badge jumeau + la palette) plutôt que de modifier le test.
- **P9 mobile** : verrouiller dans le temps en ajoutant un **projet Playwright `mobile-chromium`** (Pixel 7) qui rejoue les 24 specs en viewport mobile. Cibles tactiles ≥ 44px sur header/actions principales (liens footer légaux et « Annuler » restés à ~32px : acceptés, liens secondaires).
- **États vides leads** : `availableCategories` ne listait que les catégories présentes dans les leads → l'état vide « Aucun lead pour cette catégorie » était du **code mort**. Fix : lister les 6 catégories fixes de `CATEGORY_LABELS` (le pro peut filtrer sur une catégorie sans résultat et voir l'état vide).
- **P5** : tentative e2e via `page.route` **abandonnée** — les appels Supabase du service role partent du serveur Nitro, non interceptables par Playwright. Suivi du pattern existant (`stripe-webhook.test.ts`) : extraction de l'orchestration dans `server/utils/handleLeadDecision.ts` (supabase injecté) + 9 tests unitaires. L'endpoint devient un wrapper fin.
- **`test-fix`** : supprimée (déchet local).
