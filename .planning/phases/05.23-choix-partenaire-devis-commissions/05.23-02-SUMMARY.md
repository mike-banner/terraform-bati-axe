# Phase 05.23 Plan 02 : choix de l'artisan par le partenaire (serveur) Summary

Le partenaire voit, par lot, les artisans intéressés et en retient un seul, ou une entreprise hors plateforme.

## Livré

- vue à jeton des artisans intéressés par lot (fiche publique, téléphone seulement après avenant signé)
- `POST /api/v1/b2b/engagement/[token]/select` : retenu pour l'artisan choisi, non obtenu pour les autres
- e-mails retenu / non obtenu, motifs du lien partenaire

## Fichiers principaux

- `server/api/v1/b2b/engagement/[token].get.ts`
- `server/api/v1/b2b/engagement/[token]/select.post.ts`
- `server/api/v1/admin/b2b-requests/[id]/partner-link.post.ts`
- `server/utils/signature.ts`

## Décisions

- Un seul artisan par lot ; le cas « retenu hors plateforme » ferme le lot pour tous.
- Le téléphone n'est jamais donné avant l'avenant (D-08) ; l'e-mail de l'artisan ne sort pas vers le partenaire.
