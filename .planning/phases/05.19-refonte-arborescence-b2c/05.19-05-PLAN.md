# 05.19-05 — Pro « Entreprise Générale du Bâtiment » (EGB)

Décision 2026-10-09 : le type `generaliste` de la D-01 devient `entreprise_generale` (libellé « Entreprise Générale du Bâtiment », EGB, validé par le client/utilisateur). Le terme « tous corps d'état » reste une description, pas le nom du type.
Distinct du maître d'œuvre (conçoit/coordonne, n'exécute pas).

## Règles
- Le EGB ne sélectionne aucun métier : `categories = []` et reçoit tous les chantiers/leads.
- Activation **jamais automatique** : validation admin obligatoire (sinon n'importe quel pro coche EGB pour tout récupérer).
- Le SIRET (code NAF déjà stocké dans `professionals.siret_naf_code`) est un **signal pour l'admin**, pas une décision auto.

Nécessite la colonne `professional_type` du plan 05.19-01 (migration `20260915000000`). À faire après 01 et 03.
