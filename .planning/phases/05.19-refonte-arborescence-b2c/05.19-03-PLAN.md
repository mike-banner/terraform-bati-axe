2. **Pseudo-code implementation (from MATCHING-ARCHITECTURE.md):**
   ```typescript
   // Get professional with type + categories
   const { data: pro } = await supabase
     .from('professionals')
     .select('id, subscription_status, categories, professional_type')
     .eq('id', user.id)
     .single()

   const proType = pro.professional_type || 'specialiste'
   const proCategories = pro.categories || []

   // Fetch all qualified projects (existing logic)
   const { data: projects } = await supabase
     .from('projects')
     .select('id, selected_items, selected_category, qualify_score')
     .eq('zone', proZone) // or matching logic, TBD
     .gte('created_at', thirtyDaysAgo)

   // Filter leads by matching rule
   const matchedLeads = projects.filter(project => {
     const selectedItems = project.selected_items || []

     // Rule 1: Généraliste receives all leads
     if (proType === 'entreprise_generale') {
       return true
     }

     // Rule 2: Spécialiste receives if ≥1 item overlap
     for (const item of selectedItems) {
       const rule = COMPATIBILITY_MATRIX[item]
       if (!rule) continue // unknown item, skip

       // Check if pro's categories overlap with specialistMatches
       for (const proCategory of proCategories) {
         if (rule.specialistMatches?.includes(proCategory)) {
           return true // found overlap!
         }
       }
     }

     return false // no overlap found
   })

   // Apply masking, free grants, pagination (existing logic)
   const leads = matchedLeads.map(project => maskLead(project, pro, isPremium, grantedSet))
   return { leads, isPremium }
   ```

3. **Key changes from current implementation:**
   - Replace `.in('category', proCategories)` with loop-based overlap check
   - Check `professional_type === 'entreprise_generale'` first (early return for all)
   - Use `COMPATIBILITY_MATRIX[item].specialistMatches` to determine match
   - Handle unknown items gracefully (skip, don't error)

4. **Preserve existing logic:**
   - Free grant lookup + masking (maskLead helper)
   - Premium status check

   - Error handling (404 if pro not found, 401 if not authed)
