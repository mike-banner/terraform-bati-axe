## 1. Tableau Matching (Qui reçoit quoi)

### Règle de Base
- **Généraliste** : reçoit **TOUS** les leads
- **Spécialiste** : reçoit seulement si ≥1 item du projet chevauchent ses catégories cochées

### Cas d'Usage Détaillés

#### A. Rénovation Globale
**Items** : [maçonnerie, charpente_couverture, menuiserie_ext, isolation_platrerie, menuiserie_int, plomberie_sanitaire, revêtement_sol, peinture_finitions, électricité]

| Projet coche | Généraliste | Spécialistes reçus |
|---|---|---|
| [maçonnerie] | ✅ | Maçon (overlap maçonnerie) |
| [maçonnerie, peinture_finitions] | ✅ | Maçon + Peintre |
| [charpente_couverture, isolation_platrerie] | ✅ | Couvreur + Isolation |
| [plomberie_sanitaire, électricité] | ✅ | Plombier + Électricien |

#### B. Rénovation Énergétique
**Items** : [pac, chaudiere_reno, borne_irve, vmc_chauffage, isolation_ite_iti, geothermie, poele_bois_granules, photovoltaique, menuiserie_ext_rge]

**RÈGLE SPÉCIALE** : Si particulier coche **que** des items "généralistes" (PAC seule, solaire seul, etc.), **généraliste seulement**. Sinon, match spécialiste.

| Projet coche | Généraliste | Spécialistes reçus |
|---|---|---|
| [pac] | ✅ | **PAC = généraliste only** (besoin coordination chauffagiste/élec) |
| [photovoltaique] | ✅ | **Solaire = généraliste only** (installateur externe) |
| [isolation_ite_iti, électricité] | ✅ | Isolation + Électricien (électricité = composite) |
| [geothermie] | ✅ | **Généraliste only** (spécialiste rare) |
| [borne_irve, électricité] | ✅ | Électricien |

**Raison** : PAC/Solaire/Géothermie sont des équipements coordonnés → pas de spécialiste seul pertinent. Les artisans locaux qui en posent le font dans une EG. Électricité toutefois peut se coupler à d'autres items → reçue comme item "liant".

#### C. Prestations Ciblées
**Items** : [salle_de_bain, cuisine, toiture, façade, extension, surélévation, combles, démolition, terrasse, clôture_portail, assainissement]

| Projet coche | Généraliste | Spécialistes implicites |
|---|---|---|
| [salle_de_bain] | ✅ | Carreleur + Plombier (groupe implicite) |
| [cuisine] | ✅ | Menuisier |
| [toiture] | ✅ | Couvreur (ou Maçon si charpente) |
| [façade] | ✅ | Maçon |
| [extension, charpente_couverture] | ✅ | Maçon + Couvreur |
| [terrasse] | ✅ | Maçon |
| [combles] | ✅ | Isolation + Menuiserie (groupe) |
| [clôture_portail] | ✅ | Maçon |
| [démolition] | ✅ | **Généraliste only** |
| [assainissement] | ✅ | **Généraliste only** |

## 3. Architecture Matrice Scalable (Partenaires)

### Modèle Proposé : Matrice Application-Layer (TS)

**Pattern** : fichier statique `app/utils/workTypeMatrix.ts` (ou `.json` consulté à la compile).

**Structure** :
```typescript
// app/utils/workTypeMatrix.ts
export const COMPATIBILITY_MATRIX: Record<string, CompatRule> = {
  pac: {
    defaultRole: 'entreprise_generale',
    specialistMatches: [],
    label: 'Pompe à Chaleur',
  },
  salle_de_bain: {
    defaultRole: 'any',
    specialistMatches: ['carreleur', 'plombier'],
    groupingStrategy: 'implicit_team', // propose carreleur+plombier ensemble
    label: 'Salle de Bain',
  },
  cuisine: {
    defaultRole: 'any',
    specialistMatches: ['menuisier'],
    groupingStrategy: 'single',
    label: 'Cuisine',
  },
  // ... 23 items
}

export const PROFESSIONAL_CATEGORIES: Record<string, string> = {
  maconnerie: 'Maçonnerie & Gros Œuvre',
  toiture: 'Toiture',
  electricite: 'Électricité',
  plomberie: 'Plomberie & Chauffage',
  peinture: 'Peinture',
  isolation: 'Isolation',
  carrelage: 'Carrelage',
  menuiserie: 'Menuiserie',
  renovation_energetique: 'Rénovation Énergétique',
}
```

**Avantages** :
- ✅ Zéro requête DB pour le matching
- ✅ Étendu facilement : ajouter une ligne dans la matrice
- ✅ Versionnable en git
- ✅ Testable isolement

### Pseudo-code Matching (Nitro)

```typescript
// server/api/v1/leads/index.get.ts
const selectedItems = project.selected_items || []
const proCategories = pro.categories || []

// Cas généraliste
if (pro.professional_type === 'entreprise_generale') {
  return true // reçoit tout
}

// Cas spécialiste
for (const item of selectedItems) {
  const rule = COMPATIBILITY_MATRIX[item]
  if (rule?.specialistMatches?.includes(proCategory)) {
    return true // overlap trouvé
  }
}
return false // aucun overlap
```
