## Périmètre
1. **Convention cadre** signée une fois par le pro **et** par le partenaire (non-contournement 24 mois, commission D-01, pénalité forfaitaire, information du client final, juridiction). Sans convention signée : pas de positionnement (pro) / pas de diffusion du dossier (partenaire).
2. **Avenant par lot** : généré au clic « Se positionner », référence dossier + lot + partenaire + taux + durée ; signé par le pro (OTP) **avant** que le serveur démasque les coordonnées (même invariant que ADR-004 / `maskLead`).
3. **Table de preuve `b2b_engagements`** (RLS dans la même migration, écriture service role uniquement).
4. **Suivi** : statut `signé → devis déclaré → acompte versé → facturé` ; montant du devis déclaré par le pro, **confirmé par le partenaire** ; relances J+30 / J+60 si rien n'est déclaré ; vue admin dans l'onglet Dossiers B2B.
