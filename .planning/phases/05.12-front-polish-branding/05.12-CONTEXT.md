## Pourquoi cette phase
Deux chantiers front indépendants livrés dans la foulée de 05.10/05.11, hors flux GSD :

1. **Landing page Partenaires dédiée** — le bouton « Partenaires » du header menait à la page mixte `b2b/partenaires.vue` (landing + tunnel dans le même fichier). L'utilisateur voulait une **vraie page d'accueil dédiée** qui explique en détail les services aux apporteurs d'affaires, avec des CTAs qui lancent le tunnel.
2. **Déclinaisons web du logo** — le logo fourni était un PNG 1536×1024 **RGB sans transparence** (fond blanc) ; il fallait le détourer et produire les déclinaisons standard du web (favicons, apple-touch-icon, icônes PWA, carte de partage social, versions monochromes).

## Décisions
- **URL** : nouvelle landing sur `/partenaires` (court, mémorisable) ; le tunnel garde `/b2b/partenaires` (formulaire seul) ; le lien « Partenaires » du header/footer pointe sur la landing ; le lien est masqué quand on est sur l'une des deux pages (`isPartenairesPage`).
- **Type de page** : landing page dédiée (page de conversion B2B) en 9 sections — hero → barre de confiance → problème/solution → services détaillés → comment ça marche (4 étapes) → pour qui (profils) → conformité → FAQ → CTA final.
- **Scroll fluide** : `scroll-behavior: smooth` global sur `<html>` (bénéfice pour tous les ancres du site), désactivé si `prefers-reduced-motion`.
- **Copy CTA** : « Voir comment ça marche » → « Découvrir le processus » (règle UX copy : verbe + objet, sens autonome).
- **Détourage logo** : flood-fill depuis les bords (préserve les zones blanches internes du design — ~38% de blanc interne), adoucissement des halos, recadrage au plus juste (761×688 ; le mark était noyé dans ~1/3 de marges blanches invisibles).
- **Variantes monochromes** : blanc (fonds sombres) et slate-900 (fonds clairs) — le logo est slate (~24%) + orange sécurité (~37%) + blanc interne (~38%).
- **Script réutilisable** `scripts/generate-logo-variants.mjs` : régénère tout (`node scripts/generate-logo-variants.mjs`) si le logo change.
