# Plan Phase 05.17-01: Integration Partenaires Diagnostiqueurs (P19)

1. Ajouter le profil Diagnostiqueur Immobilier sur la landing et le tunnel `/b2b/partenaires`.
2. Créer l'interface de dépôt de rapport/opportunité travaux post-DPE.
3. Câbler la génération automatique de dossiers B2B à destination de la console admin et du réseau pro.

- Task 3 : Câbler la notif Resend + inscription dans `b2b_requests`.

## Verification Protocol
