```ts
export const TENDER_EXPIRY_DAYS = 14 // D-07

export interface ExpiryCandidate { id: string; status: string; reference_at: string | null }

/** Pure : lots ouverts dont la diffusion date de plus de TENDER_EXPIRY_DAYS. */
export function selectExpiredLots(lots: ExpiryCandidate[], now: Date): string[] {
  return lots
    .filter(l => l.status === 'open' && l.reference_at
      && (now.getTime() - new Date(l.reference_at).getTime()) / 86_400_000 >= TENDER_EXPIRY_DAYS)
    .map(l => l.id)
}
```

Handler :
1. Même garde `cronSecret` que `decennale-alerts.get.ts` (401 `'Non autorisé.'`).
2. `const supabase = await serverSupabaseServiceRole(event) as any`.
3. Lots ouverts : `.from('b2b_tender_lots').select('id, status, created_at').eq('status', 'open').limit(1000)`.
4. Date de référence = date de **diffusion** et non de création (un lot peut rester non diffusé
   plusieurs jours après l'intake) : charger
   `.from('b2b_tender_notifications').select('lot_id, sent_at').in('lot_id', lotIds)` et retenir le
   `MIN(sent_at)` par `lot_id` (réduction en mémoire, pas de RPC). Pour un lot sans aucune
   notification, `reference_at = null` → jamais expiré (il n'a jamais été proposé à personne).
5. `const expired = selectExpiredLots(candidates, new Date())`.
6. Si non vide : `.from('b2b_tender_lots').update({ status: 'closed', closed_at: now.toISOString(), closed_reason: 'expired' }).in('id', expired)`.
7. Retourner `{ status: 'SUCCESS', checked: lots.length, closed: expired.length }`.

## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| Internet → endpoint cron | Endpoint HTTP GET public par construction, protégé uniquement par un secret partagé |
| artisan authentifié → POST report | Texte libre stocké puis réaffiché dans une page admin |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-09-10 | Spoofing | `close-expired-tenders.get.ts` | mitigate | Comparaison stricte `authorization === \`Bearer ${cronSecret}\`` + refus si `cronSecret` vide (même garde que `decennale-alerts.get.ts`) |
| T-09-11 | Tampering | clôture de masse | mitigate | L'endpoint ne peut que passer `open` → `closed` avec `closed_reason: 'expired'`, jamais rouvrir ni supprimer ; `limit(1000)` borne le lot traité |
| T-09-12 | Tampering / XSS | `report.post.ts` → `AdminB2bTab.vue` | mitigate | `reason` restreint à un `z.enum` de 5 valeurs, `details` borné à 500 caractères, rendu via interpolation Vue `{{ }}` (échappement automatique) — jamais de `v-html` |
| T-09-13 | Denial of Service | signalements en masse | mitigate | `report_reasons` tronqué aux 20 derniers éléments (`.slice(-20)`), endpoint authentifié |
| T-09-14 | Information Disclosure | réponse de `report.post.ts` | mitigate | La réponse est `{ status: 'SUCCESS' }` uniquement — le compteur de signalements reste côté admin |
</threat_model>
