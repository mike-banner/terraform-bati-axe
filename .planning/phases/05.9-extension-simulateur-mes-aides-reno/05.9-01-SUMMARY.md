# 05.9-01 Summary — Proxy Nitro aides-reno + resolver CP→INSEE + persistance

**Status:** ✅ Complete
**Date:** 2026-08-18

## Livré
- `server/utils/codePostalToInsee.ts` — résolution code postal → INSEE via `geo.api.gouv.fr`, cache mémoire (`Map<string, string | null>`), timeout 5s, ne throw jamais.
- `server/utils/aidesReno.ts` — `buildSituationQuery` (mapping FERMÉ whitelist, valeurs entre guillemets simples, clés accentuées sans espaces) + `computeAidesSummary` (somme des subventions numériques, prêts exclus, reste à charge local = coût − aides).
- `server/api/v1/aides-reno.post.ts` — endpoint proxy `POST /api/v1/aides-reno` : Zod, résolution INSEE, `$fetch` vers `mesaides.france-renov.gouv.fr/api/v1` (timeout 8s), dégradation `{ ok:false }` sur toute panne.
- `server/api/v1/projects.post.ts` — `calculator_data` étendu de 3 champs optionnels (`aides_estimees`, `reste_a_charge_min`, `reste_a_charge_max`), aucune migration.

## Vérification
