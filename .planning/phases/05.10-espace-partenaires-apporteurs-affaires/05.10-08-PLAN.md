# Plan 05.10-08 — Workflow DirCo (human-in-the-loop)

## Objective
Permettre au chargé d'affaires de qualifier un dossier B2B (pièces CCTP déjà consultables dans l'onglet), sélectionner 2-3 sous-traitants vérifiés et les restituer au donneur d'ordres (email), avec traçabilité dans le pipeline.

## Deliverables
1. Migration : colonnes `qualifications_requises text[]`, `planning_start date`, `planning_end date`, `recommended_pros uuid[]` sur `b2b_requests`.
2. GET b2b-requests : retourne aussi les pros vérifiés (picker sous-traitants) — id, company_name, category, canonical_slug, postal_code.
3. PATCH b2b-requests/[id] : accepte les champs DirCo (Zod — dates ISO, uuid[] ≤ 3, text[] ≤ 20 items ≤ 100 chars).
4. POST b2b-requests/[id]/restitution : email au donneur d'ordres (sous-traitants + lien profil public `/pro/{dept}/{slug}`), statut → 'qualifie', note + audit log.
5. AdminB2bTab : section « Qualification DirCo » (qualifications, planning, picker pros max 3, bouton restitution).

## Notes de conception
- `cctp_files` du draft CONTEXT écarté : redondant avec `b2b_requests.files` (toutes les pièces y sont déjà, consultables dans l'onglet).
- V1 : « sous-traitants validés » = pros `is_verified = true` (Phase 05.11 filtrera sur les documents légaux).
- L'URL profil public : `/pro/{dept}/{canonical_slug}` (dept = 2 premiers chiffres de postal_code, pattern existant AdminProCard).
