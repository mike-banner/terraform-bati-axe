## Process DirCo (human-in-the-loop — cf. spec 2026-08-18 §2.3)
Le modèle Bâti Axe n'est pas 100 % self-service (différenciateur vs Arti-Box) : à la réception d'un dossier `b2b_requests` (projet immédiat + CCTP), le **DirCo / chargé d'affaires** :
1. Analyse le CCTP et les pièces (fichiers R2).
2. Qualifie le besoin (lot technique, exigences Qualibat/RGE, planning).
3. Sélectionne **2-3 sous-traitants validés** (via `documents_artisan` valides — Phase 05.11).
4. Présente ces sous-traitants au donneur d'ordres et suit le pipeline (`b2b_requests.status` + `assigned_to`).

Schéma : ajouter à `b2b_requests` les champs `cctp_files` (jsonb), `qualifications_requises` (text[]), `planning_start`/`planning_end` (dates), `recommended_pros` (uuid[]).
